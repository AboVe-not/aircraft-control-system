# Интерактивное исследование систем управления самолётом

Проект моделирует продольное движение самолёта и позволяет исследовать системы управления нормальной перегрузкой и углом тангажа. В MATLAB можно менять коэффициенты регуляторов, частоту и демпфирование привода, наблюдать переходные процессы и оценивать устойчивость замкнутой системы.

Программа сравнивает начальную настройку по методу стандартных коэффициентов, результат ограниченного численного уточнения, встроенную справочную настройку и текущие значения ползунков. Справочные коэффициенты приведены для сравнения. Они не являются результатом оптимизации этой программой.

## Физическая модель

Рассматривается линейная модель продольного движения самолёта. Её состояние задают угол атаки \(\alpha\), угловая скорость тангажа \(\omega_z\) и угол тангажа \(\theta\). Управляющее воздействие подаётся через отклонение руля высоты \(\delta_e\).

На движение также могут влиять вертикальный поток воздуха и внешний момент. В модели они представлены входами \(\alpha_w\) и \(m_z=M_z/I_z\), где \(m_z\) является эквивалентным угловым ускорением.

Настройки модели по умолчанию находятся в `+ACS/default_config.m`:

| Параметр | Значение | Смысл |
|---|---:|---|
| \(H\) | 4 км | Высота, заданная в конфигурации |
| \(V\) | 800 км/ч, 264 м/с | Скорость, заданная в конфигурации |
| \(M\) | 0,81 | Число Маха |
| \(c_1\) | 0,60 | Коэффициент линеаризованной модели |
| \(c_2\) | 8,80 | Коэффициент линеаризованной модели |
| \(c_3\) | 15,80 | Коэффициент линеаризованной модели |
| \(c_4\) | 1,10 | Коэффициент линеаризованной модели |
| \(c_5\) | 0,220 | Коэффициент линеаризованной модели |
| \(c_6/g\) | 0,470 | Масштабный коэффициент в уравнении перегрузки |
| \(c_9\) | 0,180 | Коэффициент линеаризованной модели |
| \(\Omega_{пр}\) | 30 рад/с при запуске | Собственная частота модели привода |
| \(\xi_{пр}\) | 0,8 | Относительное демпфирование привода |

Значения коэффициентов модели являются параметрами конфигурации. В интерактивном окне меняются коэффициенты регулятора, частота и демпфирование привода. Коэффициенты модели самолёта через интерфейс не меняются.

## Структура системы

Внутренняя система формирует команду рулю высоты по сигналу ошибки перегрузки и обратной связи по угловой скорости. Для тангажа к ней добавляется внешний контур, который преобразует ошибку угла тангажа в команду внутреннему контуру.

Привод моделируется апериодическим звеном второго порядка:

\[
W_{пр}(s)=\frac{\Omega_{пр}^{2}}{s^{2}+2\xi_{пр}\Omega_{пр}s+\Omega_{пр}^{2}}.
\]

Для статического внутреннего контура регулятор содержит коэффициенты \(K_n\) и \(K_\omega\). В астатическом контуре добавляется интегральное звено с коэффициентом \(K_i\). Для системы тангажа используется внешний коэффициент \(K_\theta\).

| Система | Состав регулятора | Что отслеживается |
|---|---|---|
| Статическая перегрузка | \(K_n, K_\omega\) | Нормальная перегрузка \(n_y\) |
| Астатическая перегрузка | \(K_n, K_\omega, K_i\) | Нормальная перегрузка \(n_y\), с интегральной составляющей |
| Статический внутренний контур тангажа | \(K_n, K_\omega, K_\theta\) | Угол тангажа \(\theta\) через внутренний контур перегрузки |
| Астатический внутренний контур тангажа | \(K_n, K_\omega, K_i, K_\theta\) | Угол тангажа \(\theta\), с интегральной составляющей |

## Расчётные уравнения

### Уравнения движения

В коде объект записан в пространстве состояний:

\[
\dot{x}=Ax+Bu, \qquad y=Cx+Du,
\]

где

\[
x=\begin{bmatrix}\alpha&\omega_z&\theta\end{bmatrix}^{T},\qquad
u=\begin{bmatrix}\delta_e&\alpha_w&m_z\end{bmatrix}^{T},\qquad
y=\begin{bmatrix}n_y&\omega_z&\theta\end{bmatrix}^{T}.
\]

Матрицы модели строятся в `+ACS/plant_matrices.m`:

\[
A=\begin{bmatrix}
-c_4&1&0\\
-c_2+c_5c_4&-c_1-c_5&0\\
0&1&0
\end{bmatrix},\qquad
B=\begin{bmatrix}
-c_9&-c_4&0\\
-c_3+c_5c_9&-c_2+c_5c_4&1\\
0&0&0
\end{bmatrix},
\]

\[
C=\begin{bmatrix}
k c_4&0&0\\
0&1&0\\
0&0&1
\end{bmatrix},\qquad
D=\begin{bmatrix}
k c_9&k c_4&0\\
0&0&0\\
0&0&0
\end{bmatrix},\qquad k=\frac{c_6}{g}.
\]

Передаточные функции каналов объекта вычисляются из этой модели. Для описания характеристического полинома в коде используются следующие полиномы:

\[
D_a(s)=s^2+(c_1+c_4+c_5)s+(c_2+c_1c_4),
\]

\[
N_n(s)=k\left[c_9s^2+c_9(c_1+c_5)s-c_3c_4+c_2c_9\right],
\]

\[
N_\omega(s)=-(c_3-c_5c_9)s-(c_3c_4-c_2c_9).
\]

Обозначим знаменатель привода через

\[
F_{пр}(s)=s^2+2\xi_{пр}\Omega_{пр}s+\Omega_{пр}^2.
\]

Тогда характеристические полиномы четырёх замкнутых систем в принятой в коде записи имеют вид

\[
\begin{aligned}
\Delta_{n,ст}(s)={}&F_{пр}(s)D_a(s)-\Omega_{пр}^2\left[K_nN_n(s)+K_\omega N_\omega(s)\right],\\
\Delta_{n,аст}(s)={}&sF_{пр}(s)D_a(s)-\Omega_{пр}^2\left[K_nsN_n(s)+K_\omega sN_\omega(s)+K_iN_n(s)\right],\\
\Delta_{\theta,ст}(s)={}&sF_{пр}(s)D_a(s)-\Omega_{пр}^2\left[K_nsN_n(s)+K_\omega sN_\omega(s)+K_nK_\theta N_\omega(s)\right],\\
\Delta_{\theta,аст}(s)={}&s^2F_{пр}(s)D_a(s)-\Omega_{пр}^2\left[K_ns^2N_n(s)+K_\omega s^2N_\omega(s)+K_isN_n(s)+K_iK_\theta N_\omega(s)\right].
\end{aligned}
\]

Устойчивость определяется по коэффициентам характеристического полинома критерием Гурвица. Граница области соответствует настройкам, при которых хотя бы один определитель Гурвица обращается в ноль. В интерфейсе также отображается годограф Михайлова для текущего полинома.

### Начальная настройка и её уточнение

Начальные коэффициенты вычисляются в `+ACS/standard_coefficients.m` методом стандартных коэффициентов. Для выбранной системы строится характеристический полином с идеальным приводом, задаётся желаемый полином и приравниваются его нормированные коэффициенты к коэффициентам модели. Полученная настройка затем проверяется для полной модели с динамическим приводом.

Полюса желаемых полиномов по умолчанию задаются в `+ACS/default_config.m`. Они определяют начальную расчётную форму и не являются автоматическим доказательством оптимальности. После начального расчёта программа выполняет ограниченный численный поиск коэффициентов с проверкой устойчивости и показателей качества.

Справочные значения коэффициентов используются только как отдельная кривая для сравнения. Они не подменяют найденную настройку и не участвуют в численном уточнении.

## Что показывает интерфейс

Основная вкладка содержит три графика переходных процессов:

1. Отработка ступенчатого задания. Для перегрузочного контура задаётся \(1\,g\), для тангажа задаётся \(1^\circ\).
2. Реакция на постоянное моментное воздействие. В модели используется эквивалентное угловое ускорение \(m_z=1^\circ/с^2\).
3. Реакция на вертикальный поток, представленный эквивалентным приращением угла атаки \(\alpha_w=1^\circ\).

Требования по перерегулированию и времени установления относятся к графику отработки задания. Время установления определяется по коридору \(\pm5\%\) от конечного значения. Для каналов с конечным значением около нуля применяется коридор относительно пикового отклонения. Реакции на момент и поток показывают поведение системы при возмущениях.

На правой стороне окна показываются карта устойчивости в плоскости \((K_n,K_\omega)\), годограф Михайлова и таблица показателей. Карта устойчивости строится для текущих значений остальных коэффициентов. Для астатического контура и тангажа карта является сечением многомерного пространства коэффициентов при фиксированных значениях остальных параметров.

Вкладка «Влияние c и частоты привода» показывает, как меняется область устойчивости при однофакторном изменении коэффициентов модели и частоты привода. Для статического контура перегрузки используются \(c_1=0{,}3; 0{,}6; 0{,}9\), \(c_2=4{,}4; 8{,}8; 13{,}2\), \(c_9=0; 0{,}18; 0{,}36\) и \(\Omega_{пр}=10; 15; 20\) рад/с. Для астатического контура перегрузки строятся те же серии при фиксированном \(K_i=5{,}25\), а отдельная серия сравнивает \(K_i=2{,}625; 5{,}25; 7{,}875\). В этом исследовании подбор регулятора не повторяется, изменяется только выбранный фактор.

## Установка и запуск

### Требования

- MATLAB R2025b, версия, в которой проверен проект
- Control System Toolbox для моделирования линейных систем и расчёта переходных процессов
- Simulink требуется только для создания и запуска блочных моделей

### Запуск окна

1. Скачайте репозиторий с GitHub через **Code → Download ZIP** и распакуйте архив, либо клонируйте репозиторий через GitHub Desktop.
2. В MATLAB выберите **Home → Open** и откройте корневую папку проекта.
3. В Command Window выполните:

```matlab
run_mode
```

Основной файл запускает `interactive_mode.m`. Для прямого открытия интерфейса можно выполнить:

```matlab
interactive_mode
```

Если MATLAB сообщает, что не найдена функция из пакета `ACS`, убедитесь, что текущая папка MATLAB является корневой папкой проекта, где находится `+ACS`.

## Работа с интерфейсом

1. В списке «Исследуемая система» выберите один из четырёх контуров.
2. Выберите отображаемый интервал времени и количество дополнительных кривых для сравнения.
3. Задайте частоту привода от 5 до 30 рад/с с шагом 5 и относительное демпфирование \(\xi_{пр}\).
4. Меняйте доступные коэффициенты ползунками. Графики обновляются при изменении значений.
5. Нажмите «Зафиксировать для сравнения», чтобы оставить текущую кривую на графиках.
6. Нажмите «Принять за исходную», чтобы сохранить текущие коэффициенты как начальное положение ползунков для следующих запусков.
7. Нажмите «Уточнить», чтобы запустить ограниченный численный поиск. Предел итераций задаётся в окне. Кнопка «Остановить» прерывает поиск и оставляет лучшее устойчивое решение, найденное к этому моменту.
8. Нажмите «Сохранить графики и модели», чтобы записать графики, параметры расчёта и модели выбранной системы.

Сохранённые пользователем исходные настройки находятся в `user_baselines_workflow.mat`. Этот файл создаётся после нажатия «Принять за исходную». Если его удалить, программа использует значения по умолчанию из конфигурации.

## Изменение исходных данных

Коэффициенты модели самолёта, исходные значения регуляторов, желаемые полюса и ограничения поиска находятся в `+ACS/default_config.m`. Изменение этой функции влияет на все режимы, поэтому после редактирования следует повторно проверить расчёты.

Настройки частот однофакторного исследования и множители для сравнений задаются в полях `P.sweep`. Параметры самого интерфейса, включая шаг частоты привода, находятся в `interactive_mode.m` и `+ACS/factor_study_page.m`.

## Запуск расчёта без окна

Функция `run_mode_workflow` рассчитывает только указанную систему, сохраняет начальную, уточнённую и справочную настройки, показатели и три модели Simulink.

```matlab
R = run_mode_workflow('astatic_pitch', 30);
```

Допустимые имена систем:

```text
static_ny
astatic_ny
static_pitch
astatic_pitch
```

Второй аргумент задаёт частоту привода. Разрешены значения от 5 до 30 рад/с с шагом 5. По умолчанию результаты сохраняются в `results_workflow/<имя_системы>`. Папку можно задать третьим аргументом:

```matlab
R = run_mode_workflow('static_ny', 20, fullfile(pwd, 'my_results'));
```

Сценарий `run_experiments.m` предназначен для пакетного построения прежнего набора факторных экспериментов и графиков. Для обычной интерактивной работы он не нужен.

## Проверочные сценарии

Проверочные файлы запускаются из корневой папки проекта MATLAB. Часть из них может выполнять длительные вычисления или создавать модели Simulink.

- `check_standard_design` проверяет равенство начальных характеристических полиномов заданным полиномам
- `check_workflow` проверяет модель, критерий устойчивости и синтез для четырёх систем
- `check_workflow_limits` проверяет ограничения поиска и остановку
- `check_workflow_controls` проверяет взаимодействие элементов окна
- `check_standard_integration` проверяет интеграцию с Simulink
- `check_workflow_models` создаёт и проверяет 12 моделей, по три для каждой системы
- `check_factor_study` проверяет карты статического контура перегрузки
- `check_astatic_factor_study` проверяет карты астатического контура перегрузки

## Известные ограничения

- Используется линейная модель продольного движения с постоянными коэффициентами.
- Частота и демпфирование привода задаются пользователем. Они не вычисляются из модели самолёта.
- Численное уточнение ограничено заданными пределами параметров, временем и числом итераций. Оно не гарантирует глобальный минимум.
- Критерии качества оцениваются для отработки задания. Реакции на момент и вертикальный поток отображаются как дополнительная оценка.
- В модели момент задан через \(M_z/I_z\), поскольку отдельные физические значения момента инерции и возмущающего момента не задаются.
- Для воспроизводимых сравнений следует записывать частоту привода, демпфирование и все коэффициенты регулятора.
